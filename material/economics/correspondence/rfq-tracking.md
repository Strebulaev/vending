## 4. Критерии выбора (после получения котировок)

1. **Полнота пакета документов** (пункт 5 таблицы) — критично для сертификации.
2. **Итого door-to-door стоимость** (пункт 3) — с учётом фрахта, пошлины, НДС, брокера.
3. **Lead time** — совместим ли с целями пилота.
4. **Гарантия / сервис / запчасти** — доступность в Сербии или быстрая доставка.
5. **Протокол платежей / телеметрии** — совместимость с Nayax и локальными требованиями.
6. **Риск** — проверенность поставщика, референсы, платёжная защита.

**Порог решения 0012:** если разница door-to-door между лучшим A и B/D ≤ X% (порог определит владелец после получения котировок), предпочесть B/D (сертификация и сервис на месте). Иначе A с защитой по договору.

## 5. Следующие шаги после получения котировок

1. Заполнить таблицу сравнения (пункт 2).
2. Обновить `docs/cost-estimates/blocks/TECH.md` строка 1.1 (RO base unit) с подтверждённой ценой и источником `material/economics/prices/...`.
3. Обновить `docs/economics/ready-made-options-landed-cost.md` с фактическим FOB, фрахтом, HS кодом.
4. Пересчитать сценарии пилота: `python3 pipeline/calculator.py` → `docs/cost-estimates/pilot-scenarios.md`.
5. Обновить `docs/hardware/equipment-cost-estimate.md` и `docs/hardware/hardware-report.md` раздел 3.
6. Обновить `docs/project/pilot-launch-guide.md` §2.3 и таблицу 2.1.
7. Принять решение по варианту (A/B/D) и зафиксировать в решении владельца (0012 → active).
8. Заключить договор с выбранным поставщиком (поэтапная оплата, допуски, штрафы).
