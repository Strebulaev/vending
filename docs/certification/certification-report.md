## 2. Обоснование выбора

### 2.1 Почему «покупаем» для пилота
- **Обоснование:** Пилот — одна точка. Готовый аппарат с полным пакетом документов поставщика (CE, пищевые контакты, радио, ESIR-готовность) переносит ответственность за соответствие изделию на производителя. Наша задача — вода, фискализация, деятельность, монтаж.
- **Условие:** Поставщик предоставляет документы §3 `buy-vs-make.md` с серийной привязкой. Условие остатка платежа после проверки документов.
- **Риск:** Поддельные/чужие документы, несовпадение модели. Митигация: инспекция третьей стороной перед отгрузкой (299 USD/чел-день, `material/economics/prices/qualityinspection.org_cae37cb6`).

### 2.2 «Производим» — не раньше ~20 точек
- **Обоснование:** Требует: техническое досье, испытания EMC/LVD (лаборатория), миграция материалов (лаборатория), метрологическое одобрение типа (DMDM), декларацию соответствия, маркировку, регистрацию производства (не найдена). Экономия на единице при N>20 (формула в `master-certification.md` §6).
- **Источник:** `material/certification/documents/tehnis.privreda.gov.rs_009ce43e.pdf` (ZOTZ перевод), `material/certification/documents/ratel.rs_f8489920` (радио).

## 4. Чек-лист «Допуск к запуску» (14 пунктов)

Аппарат **не включается** без пунктов 1–12 и 14 (правило `no-launch-without-clearance-package`):

1. **Реестр/ID конфигурации** — заведен в внутреннем реестре.
2. **CE / LVD / EMC** — декларация поставщика + протоколы испытаний.
3. **Радио-сертификат** — сербский знак или CE (по Pravilnik 24/2024) с привязкой к модулю.
4. **Пищевые документы** — сертификаты/декларации контактных частей с привязкой к серии.
5. **Метрология** — одобрение типа дозатора + первичная поверка/пломба **ИЛИ** письмо DMDM об отсутствии контроля.
6. **ESIR** — сертифицированное решение для вендинга (PURS реестр).
7. **Протокол воды** — аккредитованная лаборатория: «соответствует» (основной + периодический).
8. **Санитарный акт** — письменный ответ органа: регистрация/одобрение места установки.
9. **Регистрация и договор** — юрлицо (APR) + договор аренды/размещения площадки.
10. **Условия BVK и электро** — технические условия подключения, счётчик, сброс концентрата.
11. **Приёмка** — визуальная, функциональная, документальная по чек-листу.
12. **Журнал фильтров и график анализов** — заведён, ответственные назначены.
13. **Страхование** — полис на аппарат/ОГО (опционально для пилота).
14. **Подписи** — лист допуска подписан двумя уполномоченными лицами.
