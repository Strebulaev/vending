# Мастер-сертификация стандартной конфигурации (шаг 3.1)

Дата: 2026-10-08. Курсы: pipeline/fx.py (1 EUR = 117,4601 RSD). Нормы и органы — requirements-map.md; пути — buy-vs-make.md. Цены не найдены (реестр `docs/reports/unknowns-and-open-issues.md`).
Идентификатор конфигурации: **STD-1** (условное имя; настоящий состав задаёт дорожка hardware, `docs/hardware/machine-configurations.md` в этой ветке отсутствует — ожидает дорожку hardware; после слияния заменить).

Ограничение: единый документ «мастер-сертификат» органа **в просмотренных источниках не найден** (это не утверждение, что его нет в сербском праве; подтвердить письмами органам, CE-15…CE-16). Найденные нормы работают на уровне типа, но по областям отдельно: (1) для LVD/EMC — декларация соответствия производителя на тип изделия после оценки соответствия (по английскому переводу закона о технических требованиях на tehnis.privreda.gov.rs; номер редакции закона в переводе не указан, CE-23) [web, первичный сайт министерства, перевод]; сербский «sertifikat o usaglašenosti» (CoC) по EMC/LVD с 01.01.2022 не обязателен, принимается CE для не-радио оборудования — **вторичный источник cetecomadvanced.com, текст акта не открыт** (CE-19); (2) одобрение типа меры (metrologija) — Pravilnik o načinu ispitivanja tipa merila za pojedine vrste merila, Sl. glasnik RS 22/2012 [web, paragraf.rs, заголовок открыт 2026-10-08: https://www.paragraf.rs/propisi/pravilnik_o_nacinu_ispitivanja_tipa_merila_za_pojedine_vrste_merila.html]; (3) potvrda/сертификат соответствия радио-оборудования на тип и/или модель одного производителя, действует 5 лет [web: ratel.rs/sr/radio-oprema] — но RATEL с 01.01.2025 сам оценку соответствия не проводит (по сообщению RATEL от 25.12.2024; страница сообщения в этой правке повторно не открывалась, радиоправилник 24/24 и срок potvrda 5 лет подтверждены на https://www.ratel.rs/sr/radio-oprema); кто ведёт оценку — спросить RATEL (CE-05). То есть «типовой» подход в сербском праве есть (отдельный для каждой области), но единого «мастер»-документа нет. Вода — всегда по месту. Поэтому «мастер» здесь — наш внутренний пакет типа плюс процедура, а не отдельный документ органа. Вывод о том, что единого документа нет, сделан по отсутствию в просмотренных источниках, а не по прямому утверждению нормы; подлежит подтверждению письмами (certification-report.md §8).

## 1. Определение «стандартной конфигурации»

Конфигурация = неизменяемый набор: (1) модель аппарата и версия прошивки; (2) перечень компонентов по BOM с производителем, моделью и ревизией (для контактных материалов — материал и поставщик); (3) поставщик сборки и завод; (4) схема водоподготовки (ступени, мембрана, бак) и параметры нагрева; (5) узел дозирования с расходомером/клапаном и метод пломбирования; (6) платёжно-фискальное решение и его версия; (7) радио-модули с номерами сертификатов. У конфигурации есть ID (STD-1, STD-2…), дата заморозки, ответственный и запись в реестре (§5). Серийный номер аппарата ссылается на ID конфигурации.

## 2. Одна сертификация на конфигурацию

| Область | Покрывает тип (один раз на конфигурацию) | Подтверждать для каждой единицы | Подтверждать для каждой точки |
|---|---|---|---|
| Вода | Декларации контактных материалов; схема очистки; протокол «типового» аппарата (справка) | Промывка, проверка герметичности, замена фильтров по журналу | **Протокол аккредитованной лаборатории по воде на месте** (источник и труба разные) — не переиспользуется |
| Материалы | Декларация EU 10/2011/NSF 61 по каждой позиции | Сверка серии/партии материала с реестром | — |
| Электро (LVD/EMC) | Декларация и протоколы на изделие | Проверка изоляции/заземления при приёмке | Проверка розетки/заземления на месте |
| Радио | Сертификат/CE модулей (5 лет на тип по RATEL) | Совпадение номера модуля | — |
| Метрология | Одобрение типа дозатора (если применимо) | **Первичная поверка и пломба на каждый экземпляр** (поверка — на меру) | Периодическая поверка по интервалу (водомер — 5 лет, [web]) |
| Фискализация | Сертификат ESIR на решение (у поставщика) | Привязка устройства/ключа к налогоплательщику | Регистрация точки продаж в PURS — **не найдено**, [уточнить] |
| Деятельность | — | — | Адрес/пункт продажи, договор площадки |
| Монтаж | — | — | Подключение BVK, электро, разрешение на размещение — на каждой точке |

Вывод: переиспользуется всё «типовое» (EMC/LVD, радио, материалы, одобрение типа, ESIR); не переиспользуется вода по месту, метрологическая поверка каждой меры и монтаж.

## 3. Реестр конфигураций

Поля реестра: ID; дата заморозки; BOM с ревизиями; поставщики; список документов (номера деклараций, протоколов, сертификатов RATEL/ESIR) и сроки; хэш/версия прошивки; серийные номера единиц; статус (действует / заморожена / заменена); ответственный. Хранение — `docs/certification/registry/` (создать при заморозке STD-1); бумажные оригиналы — у ответственного оператора; срок хранения документов по закону не найден (CE-14; спросить бухгалтера/юриста).

## 4. Изменение конфигурации (правила; проверяемо)

**Предложение методики, не факт и не норма**: классы A/B/C и пороги придуманы как внутренняя процедура change-control; нормативной основы не найдено, требуют утверждения владельцем (решение 0041).

Любое изменение = запись в реестре до внедрения. Классы:

| Класс | Примеры | Повторная оценка | Что делать |
|---|---|---|---|
| A — без повторной оценки | Замена крепежа, цвета, наклеек; замена фильтра/мембраны на **ту же модель того же производителя** с теми же документами; смена цвета корпуса | Нет | Запись в реестре, акт замены, проверка серии |
| B — частичная | Замена мембраны/фильтра другой моделью; замена насоса, блока питания, обогревателя на аналог с CE; смена прошивки без изменения расходомера/цены | Да, по затронутой области: документы нового компонента (CE, пищевая декларация) + внутреннее испытание; **вода — внеочередной анализ на 1 точке** | Проверить, что декларации на новый компонент есть и совпадают; обновить реестр; ID конфигурации получает ревизию (STD-1.1) |
| C — полная | Замена расходомера/узла дозирования; смена радио-модуля; смена материала бака/трубок/фитингов; смена схемы водоподготовки; изменение напряжения/мощности сверх порога (порог 10% — предложение методики, не норма; утвердить владельцу, CE-29); смена поставщика сборки | Да — **как для новой конфигурации** (STD-2): типовые документы пересобрать, при метрике — новое одобрение типа | Остановить новые установки, обновить декларации, повторить анализ на пилотной точке |

Пороги (предложение методики; числовой порог 10% — выбор автора, не норма, утвердить владельцу): класс C, если изменяется любая из позиций (5) и (7) определения, любой материал в контакте с водой, или номинальная мощность/ток более чем на 10%; класс B, если меняется марка/модель другого компонента без выхода за пороги; иначе A. Любое сомнение — класс выше.

## 5. Сроки действия и продления

- Potvrda o usaglašenosti радио-оборудования на тип/модель одного производителя: 5 лет с даты выдачи [web: ratel.rs/sr/radio-oprema]; продлить заранее.
- Протокол воды: действует до следующего периодического контроля (периодичность — **не найдено**, практика оператора в Зренянине — ежемесячно [repo]).
- Поверка меры: водомер 5 лет (строка 10), системы для жидкостей кроме воды 1 год (строка 9) [web: Pravilnik o vrstama merila, Sl. glasnik RS 37/2021, 84/2022, paragraf.rs] — какой интервал для нашего дозатора, **не найдено** [уточнить: DMDM]. Дополнительно найден Pravilnik o overavanju vodomera (номер и даты — только по поисковой выдаче, **вторичный источник, текст акта не открыт**, CE-24) — применимость к дозатору не найдена: спросить DMDM.
- EMC/LVD декларация: срок действия и порядок пересмотра при смене стандартов не найдены (CE-19); частота проверки — выбор владельца (предложение).
- Фискальное решение: сертификат ESIR — срок [уточнить: PURS].

## 6. Масштабирование на 5 / 20 / 50 точек и экономия

Таблицы «мастер / индивидуально / экономия» удалены: они строились на догадочных диапазонах цены типа и точки (цены не найдены, CE-01…CE-09), а не на данных. Остаётся только структура и формулы (символьно; значения не определены, нужны: цена типа Т по статьям buy-vs-make §5, цена на точку П):

- мастер = Т + N × П;
- индивидуально = N × (Т + П);
- экономия = индивидуально − мастер = (N − 1) × Т;
- на точку (мастер) = Т / N + П.

Следствия, не зависящие от чисел: при N = 1 экономия равна 0; экономия растёт линейно с N и пропорциональна Т. «Индивидуально» предполагает полный тип на каждую единицу — верхняя граница сравнения; если поставщик держит документы типа или орган принимает один тип на серию, Т для пути «Покупаем» мало и экономия ближе к нулю. Периодические расходы (периодические анализы, сбор APR 8 000 RSD = 68 EUR) в формулы не входят.

Расчёты для N = 5, 20, 50: **не определены** (нужны Т и П).

## 7. Условия

Мастер-подход используется только при подтверждении письмом DMDM, RATEL и Ministarstvo zdravlja, что тип можно оформить один раз; если орган требует документы на единицу, применять индивидуальный столбец. До прохождения пилота решение 0011 запрещает расходы на масштаб — формулы §6 нужны для планирования, не для траты.
