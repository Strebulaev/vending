## Правило

Если существует `docs/skills/tags.md`, все `tags` любого файла факта, решения, правила или процедуры ДОЛЖНЫ быть записями этого списка — независимо от того, написан файл через `bootstrap`/`capture`/`roadmap` или вручную. Тег вне списка фиксируется как долг: либо в списке не хватает действительно нового тега (предложить добавить с однострочным значением), либо файл должен использовать существующий тег вместо почти дубликата.
