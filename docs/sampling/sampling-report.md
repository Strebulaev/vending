## 2. Обоснование выбора

### 2.1 Конфигурация P1–P4
- **Обоснование:** Бака 30 л (решение 0020) создаёт точку накопления (P3 — слив бака до УФ). УФ после бака требует контроля на выходе (P4). P1 — контроль входа (хлор DPD, микро). P2 — контроль работы RO (TDS, металлы).
- **Риск:** Применимый раздел правилника для «прочишћена и дезинфикована вода» не подтверждён для водомата. Частота проверок не найдена в открытых нормах.
- **Источник:** `material/sampling/documents/paragraf.rs_22f0159b.html` (правилник вода), `material/sampling/documents/paragraf.rs_1e9d76a2` (правно-информационная система).

### 2.2 Правило выборки K = max(Z, ceil(N/10))
- **Обоснование:** Статистическое покрытие: при N=1 → K=1 (минимум); N=5 → K=1; N=20 → K=2; N=50 → K=5. Параметр Z (минимальное охватываемое количество) согласовывается с лабораторией/инспекцией.
- **Альтернатива:** Фиксированная частота (раз в месяц/квартал) — не найдена в нормах для водоматов.

### 2.3 Лаборатории
- **ГЗЈЗ Белград** — основная (городская). Инструкция 2023 архивирована: приём 08:00–12:00, результат 7+ дней, тел. 011/2078-605/606/636.
- **Батут (Институт)** — аккредитация № 01-130, микробиология (`material/sampling/documents/batut.org.rs_5c4e57a3.pdf`).
- **BVK лаб. санитарного контроля** — аккредитация № 01-479, физико-химия (`material/sampling/documents/bvk.rs_2527bb48.pdf`).
- **SuperLab** — аккредитация № 01-447, полный спектр (`material/sampling/certificates/super-lab.com_989af7e6.pdf`, `material/sampling/certificates/super-lab.com_50c8152a.pdf`).
- **ЗЈЗ Шабац** — единственный публичный прайс (08/2026, без налога) — ориентир, не Белград (`material/sampling/web-archive/zjz.org.rs_fb84c1f6.pdf`).
