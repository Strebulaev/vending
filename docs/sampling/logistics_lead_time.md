Числа расхода — `costs.md` раздел 8 (`pipeline/sampling_cost.py`). ## 2. Пример: поставка 8 дней, вторая партия заказывается до прихода первой

Главное правило: вторую партию нужно заказать до прихода первой, если расход за срок поставки превышает остаток.

Формула: **точка заказа ROP = расход в день x (срок поставки + страховой запас)**; заказываем по *позиции запаса* = остаток на руках + заказанное в пути (не дожидаясь прихода предыдущей партии).

Запуск 20 точек, по 2 точки в неделю, на запуск точки — 7 микро-бутылей, плюс рутина (`costs.md` §8):
- пиковый расход ≈ 3 бутылей в день (21 в неделю);
- ROP = 3 x (8 + 7) = 45 шт.

**Вариант A (маленькая первая партия, 20 шт., остаток 14 шт.).**
- день 0: заказ 1 на 20 шт., приход день 8;
- день 1: позиция 32 шт. <= ROP 45 -> заказ 2 на 60 шт. **до прихода первой партии**, приход день 9;
- день 8-9: приходят 20 + 60 шт.; остаток 76 шт.; без заказа 2 запас закончился бы к дню 5-7 и пусковые пробы встали бы на 8 дней.

**Вариант B (первая партия 60 шт.).** Заказ 1 в день 0, заказ 2 по позиции в день 15, далее каждые ~3 недели (`costs.md`).

Правило: *при сроке поставки L дней партия считается достаточной, только если Q >= расход за L + страховой запас; иначе вторая партия заказывается сразу, не дожидаясь прихода первой.* Размер партии для пилота: 1 точка — 2,5 бутыли в месяц, поэтому первая партия 108 шт. (упаковка Buddeberg, 143,20-170,41 EUR) хватит на ~3 года расхода, но срок годности/стерильности тары — [уточнить] у поставщика; для N=1 разумнее заказать 1 упаковку и получить тару у лаборатории.

## 3. График на 20 точек (недели)

| Неделя | Действие |
|---|---|
| -3 | заказ тары (8 дн.), согласование с лабораторией: договор, расписание приёма, часы, форма акта |
| -1 | приход тары, обучение пробоотборника, холостая проба |
| 1 | запуск точек 1-2: пуск (P3, P4, смыв), промывка/санобработка |
| 1-2 | результаты пуска; повторные пробы день 3 и день 7 |
| 2-3 | допуск к продаже точек 1-2 (после 2 допустимых подряд) |
| 2-10 | запуск по 2 точки в неделю; расход тары 14-21 бутыль в неделю |
| 3 (и далее по ROP) | заказ 2 (позиция запаса <= 45) |
| 5-14 | рутина: микро на точках раз в 1-2 мес |
| 12 и далее | первые полные периодические анализы кластера (год — по плану) |

Рейсы на запуске: 2 точки/неделю = 2 рейса на запуск + рейсы повторных проб (день 3, 7) -> до 6 рейсов в неделю на пике; группировать по 2-4 точки.

## 4. Допустимое время хранения и «окно» отбора

- Микро: цель до приёма 4 ч, предел 6 ч; при +4 C некоторые инструкции допускают до 24 ч — только если лаборатория подтвердит.
- Окно приёма проб лабораторией — не найдено, [уточнить] (ожидается утро пн-пт).
- Отбор в пн-ср (чтобы 48-часовая инкубация не попала на выходные); пт-вс — только по внеплановой тревоге и если лаборатория принимает (часы работы **не найдено**).

## 7. Влияние задержки на запуск точки

- Задержка поставки тары на N дней сдвигает запуск каждой точки на N дней; страховой запас 7 дней покрывает один сбой поставки.
- Задержка результата лаборатории не должна приводить к продаже воды без результата: по гардрейлу вода не выдаётся без допустимого пускового анализа.
- Каждая неделя простоя пилота: ~37 050 RSD/мес постоянных расходов / 4,3 = ~8 600 RSD в неделю без выручки [repo: pilot_scenarios.md §3 — расчёт].
