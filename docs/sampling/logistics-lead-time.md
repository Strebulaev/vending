## 2. Точка заказа: формула и пример

Формула: **ROP = d x L + SS**, где d — расход бутылей в день, L — срок поставки, SS — страховой запас (не определён). Заказ делается по позиции запаса = остаток на руках + заказанное в пути, то есть вторую партию можно и нужно заказывать до прихода первой, если расход за срок поставки превышает остаток.

Пример владельца (L = 8 дней). Иллюстрация формулы с **условными числами, не расчётом программы**: расход d = 2 шт./день, остаток 14 шт., первая партия 20 шт. заказана в день 0. Остатка хватает на 14 / 2 = 7 дней < L = 8, поэтому вторая партия должна быть заказана сразу, не дожидаясь прихода первой. Условный SS = 4 шт. даёт ROP = 2 x 8 + 4 = 20 шт.

Правило: при сроке поставки L партия достаточна только если Q >= d x L + SS; иначе следующую партию заказывают сразу.

Расход d для программы N = 1/5/20/50 — `program-costs.md` §5 (формула d = бутылей в месяц / 30). Единственная найденная упаковка с ценой — Buddeberg 250 мл стерильные с тиосульфатом, 108 шт., 143,80 EUR без НДС / 171,12 EUR с НДС (≈ 16 891 / 20 100 RSD за упаковку; 156 / 186 RSD за шт.; пересчёт по `fx.py`); на странице 2026-10-08 позиция «not in stock»; срок годности не указан — не найдено. Тару можно получить в ГЗЈЗ (комната 4), цена не найдена.

## 3. График запуска нескольких точек

Скорость запуска (точек в неделю), расход тары по неделям и число рейсов — не определены (зависят от ресурса пробоотборника и поставок). Порядок для каждой точки (предложение): заказ тары (L) и договор с лабораторией -> обучение пробоотборника, холостая проба -> пуск P1-P4 (на ведущей точке кластера) -> повторы t0 + 3 и t0 + 7 -> результаты -> допуск к продаже не раньше t0 + 14 -> рутина по `sampling-program.md`.

## 4. Окно приёма

- Приём проб: **рабочие дни 08:00-12:00** [web ГЗЈЗ]. Пробу нужно доставить до 12:00.
- Выходные и праздники: приём только по рабочим дням; календарь праздников 2026-2027 в этой версии не приводится (источник не перепроверен); сверять с официальным законом о праздниках; график работы ГЗЈЗ в праздники — не найдено, спросить лабораторию.
- Предел времени между отбором и приёмом, температура: не найдено (инструкция: «как можно короче», холод при пути дольше часа).

## 6. Влияние задержки на запуск точки

- Задержка поставки тары на N дней сдвигает запуск на N дней.
- Задержка результата лаборатории не должна приводить к продаже воды без результата (гардрейл `water-not-dispensed-without-launch-analysis`).
- Потери от простоя пилота (постоянные расходы за неделю): **не определены** (зависят от неизвестной аренды); формула: постоянные расходы в месяц / 4,33 x недели простоя.

## 7. Узкие места

1. Цены лабораторий Белграда — не найдено (звонок); срок известен только по ГЗЈЗ (7 и более дней).
2. Приём проб только по рабочим дням до 12:00.
3. Срок поставки тары (L = 8 — пример владельца), отсутствие найденного локального поставщика стерильных бутылей.
4. Мощность пробоотборника (число точек на рейс) — не определена.
5. Повторы после санобработки добавляют не менее 7 дней на точку.
6. Зависимость от hardware (пробоотборные краны, слив бака) и certification (орган и перечень проверок).
