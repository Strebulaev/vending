# Финансовая модель: формулы и найденные входы

Сгенерировано `pipeline/economics.py` (`python3 pipeline/economics.py` из корня). Курсы: `pipeline/fx.py` (1 EUR = 117,4601 RSD, 1 USD = 104,7068 RSD; данные НБС на 2026-10-06 по biznis.kurir.rs, вторичный источник). RSD округлены до целых динаров, EUR до целых евро. Метки: K1 — значение с открытой страницы/файла (URL, дата, валюта); K2 — решение владельца; «не найдено» — вход неизвестен, ID строки в `docs/reports/unknowns-and-open-issues.md`. Предложение методики — не факт. Прежние сценарные таблицы (консервативный/базовый/оптимистичный, типы локаций, сеть 1/5/20, чувствительность) удалены: они опирались на выдуманные входы (аренда, объём, комиссия, налог 10%, кража, сроки службы, общие затраты). Итоги — только «по найденным позициям».

## 2. Формулы

- Вклад с литра: **c = p × (1 − f − τ) − w**, где w = k × (тариф воды на литр забора) = k × 0,15809 RSD (+ водоотведение, если начисляется).
- Прибыль в месяц (денежная): **P = 30 × N × c − (R_rent + F_other + S)**, S — ожидаемые потери от кражи и страхование.
- Безубыточность: **N = (R_rent + F_other + S) / (30 × c)**; с амортизацией: **N = (R_rent + F_other + S + D) / (30 × c)**, где D = Σ стоимость_i / (срок_i × 12) (линейный метод — выбор конструкции, не факт).
- Окупаемость CAPEX: **T = R / (30 × N × c − R_rent − F_other − S)** месяцев, определена при знаменателе > 0.
- Цена, при которой точка безубыточна при объёме N: **p_min = ((R_rent + F_other + S)/(30 × N) + w) / (1 − f − τ)**.
- Свободные переменные: p и N. Чувствительность по ним допустима, когда все остальные входы известны; сейчас не известны R_rent, F_other, S, f, τ, k, поэтому таблиц нет.

## 3. Что вычислимо сейчас

- Выручка на гейте: 10 RSD/л × 50 л/день × 30 = **15 000 RSD/мес** (K3 из решений владельца; выручка, не прибыль; НДС в цене не учтён).
- Верхняя граница вклада: c < p − 0,15809 = **9.84 RSD/л** (при k >= 1 физически, f >= 0, τ >= 0; это граница, не оценка). Значит, безубыточный объём не меньше (R_rent + F_other + S) / (9.84 × 30); числитель не найден.
- Порог обязательной регистрации плательщиком НДС (8 000 000 RSD за любые 12 месяцев подряд, вторичный источник zuniclaw.com) достигается при обороте = выручке от воды при N = 8 000 000 / (10 × 365) = **2 192 л/день**; выручка гейта за год 180 000 RSD, то есть в 44 раза ниже порога. Остальные обороты компании не учтены.
- Безубыточность, окупаемость, прибыль в рублях: **не определено** (нужны: R_rent, F_other, S, f, τ, k, R).
