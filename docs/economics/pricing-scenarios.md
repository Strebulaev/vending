# Цена: формулы (генерируется `pipeline/economics.py`)

Курсы: `pipeline/fx.py` (1 EUR = 117,4601 RSD, 1 USD = 104,7068 RSD; данные НБС на 2026-10-06 по biznis.kurir.rs, вторичный источник). RSD округлены до целых динаров, EUR до целых евро. Метки: K1 — значение с открытой страницы/файла (URL, дата, валюта); K2 — решение владельца; «не найдено» — вход неизвестен, ID строки в `docs/reports/unknowns-and-open-issues.md`. Предложение методики — не факт.

Цена пилота — решение владельца: 50 RSD за 5 л = 10 RSD/л. Сценарные таблицы цены (5/8/10/12/15 RSD/л, эластичность e = 0,5/1,0/1,5, «минимальная цена при N л/день») удалены: они требовали аренды, постоянных расходов, комиссии, налога и объёма, которых нет (EC-05, EC-06, EC-03, EC-04, EC-08), и эластичности спроса (EC-29).

## Формулы

- Вклад с литра: c(p) = p × (1 − f − τ) − w, w = k × 0,15809 RSD.
- Безубыточная цена при объёме N: p_min = ((R_rent + F_other + S)/(30 × N) + w) / (1 − f − τ). Не определено (нужны R_rent, F_other, S, f, τ, k).
- Если цена на аппарате включает НДС по ставке v: чистая цена p/(1 + v). Ставка v для воды из аппарата не определена (20% для бутилированной воды и 10% для прочего — запись брифа, факт 0002 не проверен) (EC-32).
- Объём при другой цене: N(p) = N₀ × (p/p₀)^(−e); e не найдена, определяется экспериментом на пилоте.

## Что известно

- Выручка с одного литра = 10 RSD; вода на литр забора 0.158 RSD (тариф BVK, прочие потребители, вторичный источник); следовательно c < 9.84 RSD/л.
- Ценовые ориентиры конкурентов: `pricing.md`.
