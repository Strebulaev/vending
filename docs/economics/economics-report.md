## 2. Обоснование выбора

### 2.1 Цена 10 RSD/л
- **Обоснование:** Решение владельца 0004. Бенчмарки: Зренянин 5 RSD/л (2022, `material/economics/web-archive/zrenjaninski.com_c0be8b73`), доставка бутылей 41,8–57,7 RSD/л (`material/economics/web-archive/aparatizavodu.rs_dd6752e4`), Корлеоне 0,05 EUR/л ≈ 5,87 RSD/л (`material/economics/prices/balarm.it_2aa9fd97`). Гипотеза: жители готовы платить 2× рыночную цену за удобство и качество на месте.
- **Риск:** Готовность платить 10 RSD/л не проверена (проблемный вопрос в `unknowns-and-open-issues.md`).

### 2.2 Покупка готового аппарата (не сборка)
- **Обоснование:** Пилот — одна точка. Сборка требует: инженерии, сертификации (EMC/LVD, метрология, материалы), приёмки, тестов. Готовый аппарат переносит риски на поставщика (при условии документов). Решение 0040 (certification track) подтверждает: путь «покупаем» для пилота.
- **Условие:** Поставщик даёт полный пакет документов на серию (CE, пищевые контакты, радио, ESIR-готовность).
- **Источник:** `material/economics/prices/tinotec.en.made-in-china.com_3e3cd72d.html`, `material/economics/prices/oulepu.en.made-in-china.com_efaae641.html`, `material/economics/prices/jmpukui.en.made-in-china.com_de659c77.html` (листинги FOB).

### 2.3 Door-to-door стоимость аппарата
- **Формула:** `Price = FOB + Packaging + Freight + Insurance + Duty + Broker + PortFees + InlandDelivery + Installation`
- **Известно (3 из 10 слагаемых):**
  - FOB: 500–1 050 USD (листинги, `material/economics/prices/...`)
  - Freight LCL: 160–290 USD/m³ (один форвардер, расхождение 160–290 vs 30–56 не объяснено, `material/economics/web-archive/goodhopefreight.com_b81a525d`)
  - Insurance: 0,3–0,5% от CIF (`material/economics/web-archive/gofreight.com...` — 404, вторичный источник)
- **Неизвестно (7/10):** Duty (HS код 842121/847621 — ставка не найдена, `material/economics/web-archive/tariffnumber.com_ebd70842`, `material/economics/web-archive/tariffnumber.com_5952a17d`), Broker (DHL 45 EUR только для экспресса, `material/economics/web-archive/mydhl.express.dhl_23eb81a7.html`), PortFees, InlandDelivery, Installation, FiscalModule.
- **Диапазон по найденному:** 0,5–1,3 тыс. EUR морем LCL; 1,2–2,9 тыс. EUR авиа. **Это нижняя оценка, не door-to-door.**

### 2.4 Сборка своими силами — отложена
- Процесс описан в `in-house-assembly.md`. Цены деталей (мембрана 4040, насос, УФ, фильтры, контроллер, корпус) — не найдены (`material/economics/prices/smartbuy.alibaba.com_075e3655`, `material/economics/prices/smartbuy.alibaba.com_f6c2f80e`). Инспекция третьей стороной: 299 USD/чел-день (`material/economics/prices/qualityinspection.org_cae37cb6`, `material/economics/prices/qcadvisor.com_729cfd98`). Пересмотр на ~20 точек.
