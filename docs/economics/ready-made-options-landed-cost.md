По полной стоимости при одном аппарате накладные расходы импорта (фрахт, сборы по концам, брокер, пошлина, НДС) составляют большую часть цены A, поэтому разрыв между A и B/D заметно меньше «двойной» разницы цен; но значительная часть накладных — [заполнитель], вывод предварительный. Пересчитать по реальным котировкам.
