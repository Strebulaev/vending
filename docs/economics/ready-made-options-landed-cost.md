# Покупка готового аппарата: «от двери до двери» — формула и найденные компоненты

Сгенерировано `pipeline/economics.py`. Курсы: `pipeline/fx.py` (1 EUR = 117,4601 RSD, 1 USD = 104,7068 RSD; данные НБС на 2026-10-06 по biznis.kurir.rs, вторичный источник). RSD округлены до целых динаров, EUR до целых евро. Метки: K1 — значение с открытой страницы/файла (URL, дата, валюта); K2 — решение владельца; «не найдено» — вход неизвестен, ID строки в `docs/reports/unknowns-and-open-issues.md`. Предложение методики — не факт. Это не котировка и не оценка полной стоимости: RFQ (`docs/project/supplier-rfq.md`) не отправлен. Таблицы низ/середина/верх для A, B, D на 1/5/20 шт. удалены: они опирались на выдуманные упаковку, сборы, брокера, пошлину, доставку, установку, гарантию, множители цены B и D (k = 1,5–2,5 и 2–4), сроки (EC-10…EC-16, EC-33).

## 1. Формула

Door-to-door на аппарат = Цена_FOB + Упаковка + Фрахт + Страховка + Пошлина + Брокер + Внутренняя доставка + Установка + НДС + Резерв на гарантию.

| Слагаемое | Формула | Статус |
|---|---|---|
| Цена_FOB | листинг поставщика | найдено как объявления (§2), котировки нет |
| Упаковка | не найдено | EC-14 |
| Фрахт | ставка × объём (м³) или × вес (кг) или ÷ число аппаратов в контейнере | ставки найдены (§3), число аппаратов в контейнере не определено (кубатура знаем только у двух листингов) |
| Страховка | ставка × 1,1 × (Цена + Упаковка + Фрахт); ставка 0.3%–0.5% | K1 общий источник (https://gofreight.com/glossary/cargo-insurance: «for general ocean FCL, policies written on CIF value plus 10%»); для электроники на странице 0,5–1,0% |
| Пошлина | ставка × (Цена + Упаковка + Фрахт + Страховка) | не найдено: код тарифа и ставка Сербии не найдены (EC-11) |
| Брокер | не найдено для морского/ж/д груза; DHL Сербия: 5 265 RSD (≈45 EUR) за импортное оформление в обычном порядке для юрлиц, до 5 наименований (+600 RSD за каждое следующее), НДС в цене не указан | K1, https://mydhl.express.dhl/rs/sr/ship/customs-services.html; относится к отправлениям DHL (EC-12) |
| Внутренняя доставка, установка | не найдено | EC-15 |
| НДС | 20% × (CIF + пошлина + услуги в Сербии); не возвращается, пока компания не плательщик | ставка K1 (biznis.rs, вторичный, статья ориентирована на физлиц); база не определена |
| Резерв на гарантию | не найдено | EC-16 |

## 4. Расчёт по найденным позициям: цена листинга + фрахт + страховка (3 из 10 слагаемых)

Один аппарат, LCL считается по объёму упаковки листинга (вес брутто ниже 1000 кг/м³, поэтому «тонна или м³ — большее» даёт объём). Низ = минимальная цена, минимальная ставка, 0,3%; верх = максимальные. **Не включены (не найдены):** упаковка, пошлина, брокер, внутренняя доставка, установка, НДС, гарантия, сборы по концам, автовывоз. Итог — нижняя оценка по найденному, а не стоимость.

Выгодна ли добровольная регистрация плательщиком НДС: **не определено**. Формула: экономия на ввозном НДС (единовременно) = 20% × (CIF + пошлина + услуги) против ежемесячной потери вклада = (доля НДС в цене) × выручка × (1 − f − τ); срок равенства = экономия / потеря. Нужны: CIF, пошлина, f, τ, объём.

## 8. Сборка вместо покупки (вариант C)

Бюджет деталей, при котором сборка равна покупке A, не вычисляется: он зависел от выдуманных door-to-door A, оснастки 1 000 EUR на партию и непроверенных 16 ч интеграции. Формула: B_деталей = Door-to-door(A) − (работа + оснастка/N) × (1 + НДС на услуги); все слагаемые — не найдено (EC-20).
