## Приоритеты для пилота

1. Строка 1 (комплекс Ledine): жилой, новый, один застройщик; самое логичное первое звено. Условия: подтверждённый адрес и готовность коммерческих помещений.
2. Строки 2–4 (магазины на Vojvođanska): быстрые договоры, но нужно подтвердить воду/дренаж/место внутри.
3. Строки 6–7: амбициозные, после пилота.
4. Остальное — наблюдение.
