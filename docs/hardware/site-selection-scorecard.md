# Критерии допуска и скоринг пилотной точки

**Версия:** 0.2, стартовая методика принята владельцем  
**Дата:** 2026-10-11  
**Статус:** фильтры и равные веса приняты как стартовая методика владельцем 2026-10-11; численный проходной порог установить после сбора данных о кандидатах. Паспорт выбранной площадки и договор не найдены.

## Назначение и область

Отобрать одну уличную точку рядом с многоквартирным жилым домом в Сурчине с круглосуточным доступом жителей (решение 0003, подтверждено владельцем 2026-10-11). Скоринг не доказывает спрос и не заменяет нормативный допуск, техническое обследование или финансовую проверку. Пилот не должен отклоняться из-за отсутствия доказанной масштабной безубыточности; масштабирование остается под гейтом 0011.

## Обязательные условия (сначала «да / нет / не проверено»)

Любое «нет» означает отказ. «Не проверено» означает HOLD: баллы не начисляются и установка не разрешается.

## Оценка прошедших площадок

Оценивать каждую строку от 0 до 5 и прикладывать первичное наблюдение/документ. Число не подменяет данные: без доказательства ставится `Н/О` и вопрос не считается положительно закрытым.

| ID | Фактор | Якоря шкалы (для обследования) | Как измерить |
|---|---|---|---|
| S1 | Доступность целевой жилой аудитории | 0 — аудитория/доступ не подтверждены; 3 — подтвержден удобный доступ жителям ближайшей застройки; 5 — подтверждены несколько очевидных жилых подходов/маршрутов | Карта + полевой осмотр; количественную аудиторию не выдумывать |
| S2 | Фактический поток и возможность повторного визита | 0 — наблюдений нет/проход затруднен; 3 — поток наблюдался в части окон; 5 — устойчивый поток зафиксирован в нескольких заранее выбранных временных окнах | Ручной подсчет в одинаковых временных окнах, дата и длительность записаны |
| S3 | Круглосуточная доступность точки для жителей | 0 — часть суток закрыта; 3 — 24/7 заявлено, ограничения не проверены; 5 — круглосуточный доступ письменно согласован и проверен полевым осмотром/проходом | Условия доступа собственника/управляющего и контрольный осмотр, не предполагать доступ через общие двери |
| S4 | Видимость и понятность точки | 0 — не видна с маршрута; 3 — заметна при подходе; 5 — хорошо видна и допустима вывеска/навигация | Фото с маршрута, письменное разрешение на маркировку |
| S5 | Наблюдаемость, сохранность аппарата и безопасность наличности | 0 — скрытая/неосвещенная точка и неизвестен безопасный сервис cash-узла; 3 — часть рисков компенсируется расположением; 5 — хорошее освещение и естественное наблюдение/охрана, есть согласованный доступ для инкассации | Осмотр днем и ночью, право камеры, безопасный маршрут инкассации; не приписывать вероятность кражи |
| S6 | Экономика договора площадки | 0 — условия/платежи неизвестны или неприемлемы; 3 — получен проект понятного договора, остаются согласуемые пункты; 5 — условия письменно ясны и приняты владельцем бюджета | Коммерческое предложение/договор; балл не ставить до суммы |
| S7 | Сложность подключения и монтажа | 0 — требуется существенная неоцененная переделка; 3 — подключение возможно, часть работ не оценена; 5 — коммуникации близко, схема и смета подтверждены | Замеры, схема, осмотр специалиста, письменная смета |
| S8 | Вода, слив и раздельный учет коммунальных ресурсов | 0 — любой ресурс не подтвержден; 3 — схема возможна, условия/учет частично не подтверждены; 5 — схема и договорные условия подтверждены | Ответ BVK/владельца, данные счетчика/тарифа, план слива |
| S9 | Сервисная доступность | 0 — выезд/обслуживание затруднены; 3 — доступ возможен с ограничениями; 5 — команда может выполнять плановые и аварийные работы по согласованному доступу | Фактический маршрут и регламент доступа; численное время — не найдено до решения владельца |
| S10 | Соответствие наружному аппарату, двуформатной оплате и пробам | 0 — требования v1 не выполняются; 3 — совместимо при доработке с оцененной стоимостью; 5 — требования v1 выполняются без неразрешенных отклонений | Технический паспорт точки, матрица поставщика и программа проб |

**Расчет:** сумма баллов S1–S10, максимум 50. Все критерии равновесны (5 баллов каждый) по принятой владельцем стартовой методике; это не эмпирическая оценка важности. Численный проходной порог установить после обследования кандидатов, но до итогового ранжирования. Обязательные фильтры G1–G11 имеют приоритет над суммой баллов.

## Текущее состояние пула

В [перечне кандидатов Сурчина](surcin-candidate-sites.md) есть один подтвержденный адрес жилого комплекса застройщика в Novi Surčin—Ledine (как точка для первичного звонка, не как готовая площадка) и несколько территорий/проектов без подтвержденного конкретного места. Адрес основателя намеренно не собирается и не хранится; доступность помещения, собственник конкретного помещения, коммуникации и коммерческие условия не найдены. Поэтому пул еще не позволяет оценить ни одного кандидата; баллы и победитель не назначаются.

## Действия для закрытия этапа

1. Владелец локаций собирает кандидатов в жилом контуре Сурчина; основатель может приватно проверить близость к предпочитаемому району. Адрес его дома в документах не фиксируется. По адресу Miodraga Petrovića Čkalje 4 уточнить доступность, не предполагая, что место свободно.
2. Локации создают не менее нескольких фактически обследованных кандидатов из жилого контура; список расширяется по отклику собственников, число заранее не фиксируется как требование.
3. Для каждого пройти G1–G10; получить письменные предложения и измерения.
4. Использовать равные веса; после обследования кандидатов предложить и утвердить численный проходной порог до итогового ранжирования.
5. Юрист проверяет проект договора; основатель выбирает и письменно резервирует одну точку.
