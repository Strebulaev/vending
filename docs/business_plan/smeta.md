# Смета: Сеть вендинговых аппаратов по продаже воды (Сербия, 2026)

> **Инвестор:** Иностранное физическое лицо, планирующее открытие бизнеса в Сербии.
> **Валюта:** RSD (сербский динар). Курс для справки: 1 EUR ≈ 117 RSD.
> **Основание:** Бизнес-план вендинга воды + анализ доступных сербских грантов и субсидий для иностранцев.

---

## 1. Резюме проекта

### 1.1. Суть
Создание сети вендинговых аппаратов (водоматов) по продаже очищенной питьевой воды в розлив. Аппараты используют систему обратного осмоса (RO) для очистки водопроводной воды. Целевые локации: офисы, профессиональные кухни, жилые массивы.

### 1.2. Ключевые параметры (на 1 аппарат)

| Параметр | Значение | Источник |
|----------|----------|----------|
| **CAPEX (стартовый)** | ~970,000 RSD | Расчёт ниже |
| **OPEX (месяц)** | ~35,000 RSD | Расчёт ниже |
| **Выручка (месяц, реалистично)** | ~270,000 RSD | 5,400 л × 50 RSD |
| **Чистая прибыль (месяц)** | ~210,000 RSD | Без учёта гранта |
| **Окупаемость** | ~5 месяцев | Без гранта |
| **Окупаемость с грантом** | ~2 месяца | При покрытии 40% CAPEX |

## 5. Сербские гранты для иностранцев (КЛЮЧЕВОЙ БЛОК)

### 5.1. Доступные программы

| № | Программа | Орган | Сумма | Условия для иностранцев | Источник |
|---|-----------|-------|-------|--------------------------|----------|
| 1 | **Субсидия за самозанятость** | Национальная служба занятости (NSZ) | **380,000 RSD** (420,000 — инвалиды) | Требуется статус безработного в Сербии + пройти обучение | [citation:2][citation:10] |
| 2 | **«Vrati se i stvaraj»** | Министерство экономики + Фонд развития | До **1,800,000 RSD** | Только для граждан Сербии — возвращенцев (проживших за границей 24+ мес.) | [citation:3][citation:11][citation:18] |
| 3 | **«Kapital za razvoj»** | RAS + Poštanska štedionica | Кредит до **15,000,000 RSD** с субсидированной ставкой (2% для заёмщика) | Для микро/малых предприятий | [citation:7] |
| 4 | **StarTech** | NALED + Philip Morris | **$15,000–$100,000** | Для инновационных стартапов | [citation:4][citation:12][citation:19] |
| 5 | **Smart Start** | Инновационный фонд | До **€80,000** | Для стартапов, заявки на английском | [citation:8] |
| 6 | **Программа для начинающих предпринимателей** | Камера экономики Сербии | Кредит до **€30,000** + грант до **€3,000** | Для микро/малых предприятий (до 36 мес) | [citation:16] |

### 5.2. Применимость к проекту вендинга

| Программа | Применимость | Комментарий |
|-----------|--------------|-------------|
| **Субсидия за самозанятость** | ✅ **Высокая** | 380,000 RSD — прямое покрытие ~78% CAPEX. Требуется статус безработного (иностранец может получить после регистрации в NSZ). |
| **«Vrati se i stvaraj»** | ⚠️ **Недоступна** | Только для граждан Сербии. Иностранец не подходит. |
| **«Kapital za razvoj»** | ✅ **Высокая** | Кредит под 2% — покрывает 100% CAPEX. Нужен бизнес-план. |
| **StarTech** | ⚠️ **Средняя** | Для инновационных стартапов. Вендинг воды — не инновация. |
| **Smart Start** | ⚠️ **Низкая** | Для технологических стартапов. |
| **Начинающие предприниматели** | ✅ **Средняя** | Кредит + грант. Подходит для микро-бизнеса. |

### 5.3. Рекомендуемая стратегия

1. **Зарегистрировать ООО (DOO)** в Сербии.
2. **Встать на учёт в NSZ** как безработный (если применимо) и подать на субсидию за самозанятость — **380,000 RSD**.
3. **Подать на «Kapital za razvoj»** для покрытия остатка CAPEX — кредит под 2%.
4. **Подать на программу для начинающих предпринимателей** — дополнительный грант до €3,000.

**Итоговое потенциальное покрытие CAPEX:** до **100%**.

### 5.4. Критические замечания

- **Языковой барьер:** Все заявки на сербском языке, требуется нотариальный перевод.
- **Консультант:** Рекомендуется привлечь местного консультанта по грантам (10–15% от суммы).
- **Тайминг:** Подавать заявки **ДО** начала закупки оборудования.

## 9. Выводы

1. **CAPEX на 1 аппарат:** ~483,500 RSD (~4,130 EUR).
2. **Окупаемость:** ~2.3 месяца (без гранта).
3. **С грантом:** CAPEX покрывается на ~150%, окупаемость <1 месяца.
4. **Ключевой грант:** Субсидия за самозанятость (380,000 RSD) — **доступна иностранцам** при статусе безработного.
5. **«Vrati se i stvaraj»** — **недоступна** иностранцам (только граждане Сербии).
