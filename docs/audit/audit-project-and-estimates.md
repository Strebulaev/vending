## 2. Проверка расчётов

Запущено: `python3 pipeline/calculator.py`, `python3 pipeline/verify.py` (до и после правок), `python3 pipeline/reviewer.py` — без ошибок после правок (reviewer раньше проверял одну строку на блок).

- CAPEX по блокам пересчитан вручную: TECH 915+450+150+75+120+80+500+350 = 2 640 EUR; LOCATIONS 200+500 = 700; IT_TELEMETRY 6.5 = 100; OPERATIONS 7.1 = 800; INTEGRATION 15 строк = 1 190. Итого 5 430 EUR = 635 310 RSD. Конверсия 1000 USD × 107 / 117 = 914,5 → 915 EUR.
- Арифметика всех числовых строк (количество × цена = итог) — расхождений нет (64 строки, 10 блоков, из них 63 числовые); строка с «%» (FINANCE 3.5) обрабатывается отдельно.
- Периодичность: 3.3, 5.1, 6.2, 6.6 — monthly (делитель 1); 3.4 (every 3 months) и 7.2 (per service, квартально) — делитель 3: 25 EUR / 3 × 117 = 975, 100 / 3 × 117 = 3 900. Соответствует SCOPE; теперь проверяется кодом.
- Классификация SCOPE логична: дубликаты (3.2, 6.1, 6.3, 6.4, 7.3) исключены, гранты — источники финансирования. Замечание, не исправлено: 3.3 и 7.2 частично пересекаются, 10.14 (работа) частично пересекается с 10.10–10.13 и TECH 1.9, то есть CAPEX/OPEX может быть завышен; пометки есть.
- BLOCK_CURRENCY: GRANTS в RSD, остальные в EUR; расхождение внутри GRANTS (строки были в USD/EUR) устранено переводом блока в RSD; на итоги не влияло, так как строки исключены, но отчёт показывал неверную валюту.
