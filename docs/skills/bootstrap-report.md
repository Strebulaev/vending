## Предлагаемые навыки (решает команда)

Сначала области с необратимыми или публичными обязательствами.

- Проверка соответствия: регистрация юрлица, налоговый режим, право на гранты, публичные заявления о качестве воды. Ограничение: любое утверждение о праве или качестве ссылается на источник. Возможная проверка: поиск в docs утверждений без ссылки на факт.
- Продуктовый объём: аудитория, цены, критерий пилота. Ограничение: нет расходов на масштабирование до разбора пилота (0003, 0011). Возможная проверка: фазы плана 6.3+ заблокированы, пока не записаны метрики пилота.
- Оборудование/закупки: спецификация RO-300A, сборка, допуски. Ограничение: спецификации поставщика подтверждены письменно (0008, 0012). Возможная проверка: маркеры `[FIXED]`/«не подтверждено» в TECH_SPEC должны быть сняты до закупки.
- Процедура запуска пайплайна: нет письменного порядка router → generator → reviewer → calculator → consolidator. Ограничение: консолидированные файлы не правятся вручную без пометки. Возможная проверка: пересборка и diff в скрипте проверки.
- QA/качество смет: reviewer и verify-скрипты как барьер выпуска. Ограничение: все verify-скрипты проходят до консолидации. Возможная проверка: единая точка входа, запускающая их.
