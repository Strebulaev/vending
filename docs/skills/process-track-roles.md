- Инженер по оборудованию: конструкция аппарата, компоненты, сборка, допуски.
- Рецензент по соответствию требованиям: регистрация в Сербии, налоги, право на гранты, публичные заявления.
- Владелец QA/тестирования: скрипты проверки смет и критерии выпуска.
- Рецензент качества: замечания по сметам, прослеживаемость, согласованность между документами.
- Владелец процесса: порядок запуска пайплайна и другие повторяющиеся ручные шаги.
