*Примечания:*
- **Ключевая программа для иностранца:** «Kapital za razvoj» — кредит под 2% (эффективная ставка).
- **Кредит не покрывает CAPEX** — он его финансирует. В смете расходов его быть не должно.
- Программы 9.1, 9.2 — недоступны иностранцам без ВНЖ / вообще.
