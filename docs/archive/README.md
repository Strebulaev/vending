# Архив

Материалы здесь сохранены для истории, аудита и восстановления прежних расчётов. Они не задают текущие решения и могут содержать старые статусы, цены или варианты пилота.

## Legacy — 2026-10

Снимок документов до структурирования пяти рабочих артефактов:

- `audit-report.md` — аудит проекта и презентации на дату в документе.
- `docs-restructuring-plan.md` — план прежней реструктуризации документации.
- `presentation-v2.*`, `presentation-appendix.md` — прежняя презентация и расчётное приложение; проверить цифры и рамки перед повторным использованием.

## Текущие документы

Используйте [главную страницу](../../README.md), [карту документации](../README.md) и [интегрированный план пилота](../plans/integrated-pilot-artifacts-plan.md). Исторические файлы не нужно включать в текущие согласования, RFQ или инвестиционное решение без повторной проверки.
