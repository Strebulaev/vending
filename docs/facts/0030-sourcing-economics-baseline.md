Модель `pipeline/economics.py` содержит формулы c = p × (1 − f − τ) − w; N = (R_rent + F_other + S) / (30 × c); T = R / (30 × N × c − R_rent − F_other − S). Найдено: цена 50 RSD за 5 л (решение владельца), вода 158,09 RSD/м³ с НДС (категория «прочие потребители», вторичный источник, факт 0003) = 0,15809 RSD на литр забора. Из этого: c < 9,84 RSD/л (граница при k >= 1, f >= 0, τ >= 0); выручка на гейте 50 л/день = 15 000 RSD/мес. Не найдены: аренда, постоянные расходы, комиссия, налоговый режим, коэффициент забора, CAPEX, спрос, кража, страхование, сроки службы (реестр `docs/reports/unknowns-and-open-issues.md`). Прежние числа (безубыточность ≈157/210 л/день, убыток 18–32 тыс. RSD/мес) удалены как основанные на допущениях.
