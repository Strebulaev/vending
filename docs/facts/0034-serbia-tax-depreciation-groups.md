С 2019 года амортизация считается по каждому активу линейно; если налоговая сумма больше бухгалтерской, признаётся бухгалтерская (KPMG Сербия; Pravilnik о razvrstavanju stalnih sredstava). К какой группе относится водомат — не найдено, спросить бухгалтера. Страхование: простая кража обычно не покрывается, взлом и разбой — да; премия для оборудования не найдена (ориентир Wiener, Хорватия, 86,27 EUR/год).
