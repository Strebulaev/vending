# Пилот водомата в Сурчине

## Кратко о проекте

Подготовить запуск одного уличного водомата у жилого дома в Сурчине (Сербия). Оператор — сербское DOO. Покупатели — жители дома; доступ круглосуточный; оплата наличными и безналично. Масштабирование рассматривается после измеренного пилота.

**Сейчас:** пакет документов и расчётный pipeline подготовлены. Закупка и запуск не разрешены: не закрыты площадка, применимые требования/разрешения, подтверждённая конфигурация поставщика и финансовые входы. См. [контрольный план и статусы пяти артефактов](docs/plans/integrated-pilot-artifacts-plan.md).

## Где что редактировать

- **Параметры и текст canvas бизнес-модели:** `config/business-model-inputs.json`.
- **Общая матрица оборудования:** `docs/hardware/pilot-spec-v1.md`; профили конфигураций — `config/equipment-specifications.json`.
- **Факты, решения и обязательные правила:** `docs/facts/`, `docs/decisions/`, `docs/guardrails/` — их индексы находятся в соответствующих папках.
- **Материалы и снимки источников:** `material/`; это доказательная база, не актуальная инструкция по запуску.
- **Сгенерированные отчёты:** не редактировать вручную; менять входы и пересчитывать генератором.

## Пересборка

Из корня репозитория:

```sh
python3 pipeline/business_model.py
python3 pipeline/build_equipment_specs.py
python3 pipeline/build_equipment_specs.py --check
```

GitHub Actions: [расчёт бизнес-модели](.github/workflows/business-model-calculation.yml) и [спецификации оборудования](.github/workflows/equipment-specifications.yml). Подробные шаги: [runbook](docs/process/business-model-and-equipment-runbook.md).
