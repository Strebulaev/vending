# Водоматы в Сербии: пилот в Сурчине (Белград)

Сеть автоматов самообслуживания: городская вода очищается обратным осмосом на месте и продаётся в тару клиента за безналичный расчёт. Репозиторий содержит бизнес-документы, сметы с расчётным пайплайном, базу знаний (решения, факты, правила) и планы работ.

## Цель

Запустить **один пилотный аппарат на жилой точке в Сурчине (Белград)** и получить измеренные данные, достаточные для решения о масштабировании.

Критерий прохождения пилота (решение `0011`): среднее ≥50 л/день и аптайм ≥95% в течение 3 месяцев подряд. До этого — никаких расходов на масштабирование (правило `no-scale-out-before-pilot-gate`).

## Текущее состояние (2026-10-08)

- Расчёт `pipeline/calculator.py` показывает: при цене 50 RSD за 5 л и 50–80 л/день пилот **убыточен** (−17 000…−25 000 RSD/мес), безубыточность ≈150 л/день (оборудование и установка ≈635 000 RSD, постоянные расходы ≈37 000 RSD/мес, из них аренда 17 550). Подробности: `docs/cost-estimates/pilot-cost-summary.md`, `pilot-scenarios.md`, факт `0007`.
- Презентация (`docs/project/investor-presentation.md`) содержит устаревшие финансовые цифры и помечена об этом.
- Не найдено онлайн и требует звонков/писем: цена анализа воды, пошлина на вендинг, кто регистрирует аппараты выдачи воды, статус фискальных устройств, тарифы BVK на подключение (список — `docs/project/pilot-launch-guide.md`).

## Конкретные цели и результаты по дорожкам

Работа разделена на четыре параллельные дорожки (git worktree + ветка, план в `docs/plans/<дорожка>-track-plan.md`). Каждая выпускает итоговый документ `REPORT.md` в своей папке.

| Дорожка | Результат (папка) | Что должно быть в итоге |
|---|---|---|
| **Оборудование** `track/hardware` | `docs/hardware/` | Смета всего оборудования по позициям с ценами и источниками для 4 моделей (помещение/улица × стандарт/усиленная); полная техдокументация; бак и нагрев; телеметрия и инциденты; методика позиционирования и выбор площадки; конкретные места в Сурчине |
| **Закупки и экономика** `track/sourcing-economics` | `docs/economics/` | Финансовая модель по конфигурациям и типам локаций; цена; амортизация, кража, запас; стоимость «от двери до двери» по источникам; сборка своими силами; модель запасов со сроками поставки |
| **Сертификация** `track/certification` | `docs/certification/` | Карта сертификатов и разрешений Сербии; пути «покупаем» и «производим»; мастер-сертификация стандартной конфигурации; бюджет, сроки, чек-лист «допуск к запуску» |
| **Отбор проб** `track/sampling` | `docs/sampling/` | Стандартная конфигурация; программа проб (показатели, частота, объём, тара); правило выборки для N точек; стоимость; логистика и сроки |

Проблемы и варианты решения: `docs/reports/problems-and-options.md`.

Итог после слияния: `docs/reports/final-report.md` — сводная документация и смета (цены, шаги, оборудование и спецификации, цены с логистикой, варианты, сроки, открытые вопросы).

Принятые решения по оборудованию (в работе, статус `draft`): малый непрозрачный буфер 20–40 л вместо бака 180 л; нагрев только на уличных моделях; четыре модели из одной базы; камера во всех моделях по событиям; автоблокировка выдачи при загрязнении, вскрытии или серьёзной неисправности.

| `docs/{facts,decisions,guardrails,skills}/` | база знаний (русский), в каждой папке `INDEX.md` |

| `pipeline/` | скрипты: `generator.py`, `router.py`, `reviewer.py`, `calculator.py`, `economics.py`, `inventory.py`, `sampling_cost.py`, `verify.py`, `fx.py`; `tasks/` — задания блоков |

## Команды

```
python3 pipeline/calculator.py   # пересчитать сценарии пилота -> docs/cost-estimates/pilot-scenarios.md
python3 pipeline/verify.py       # проверить сметы (кодировка, язык, источники, классификация строк)
python3 pipeline/reviewer.py     # отчёты о проверке блоков (не хранятся в git)
```

Все скрипты запускаются из корня репозитория.

## Правила

- Язык: сметы в `docs/cost-estimates/blocks/` — английский; остальная документация и база знаний — русский. Идентификаторы, ключи frontmatter и теги — латиницей.
- У каждой цифры источник: [web] с URL, [repo] с путём, [уточнить] с названием стороны, у которой уточнить. Цены не выдумываются.
- Новая строка сметы должна быть классифицирована в `calculator.SCOPE`, иначе расчёт и проверка падают.
- Теги — только из `docs/skills/tags.md`. Номера решений и фактов: общая нумерация до 0012; дорожки используют 0020–0059.
- Курсы: 1 EUR = 117 RSD, 1 USD = 107 RSD (`pipeline/fx.py`).
